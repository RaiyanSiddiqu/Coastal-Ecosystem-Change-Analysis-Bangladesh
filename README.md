# Coastal-Ecosystem-Change-Analysis-Bangladesh
This repository contains selected scripts developed for my M.Sc. thesis in Remote Sensing and GIS.
## Research focus
Multi-temporal analysis of environmental change in coastal Bangladesh from 1995 to 2025.

## Data and methods
- Landsat satellite imagery
- NDVI, NDWI, and Land Surface Temperature time-series analysis
- Sen’s slope and Mann-Kendall trend analysis
- Land Use/Land Cover classification for 1995, 2000, 2005, 2010, 2015, 2020, and 2025
- Google Earth Engine, ArcGIS, Python, and Anaconda/Jupyter Notebook

## Repository structure
- `gee_scripts/`: Google Earth Engine JavaScript code
- `python_analysis/`: Python scripts for time-series and Sen’s slope analysis
- `figures/`: Selected maps and visual outputs
